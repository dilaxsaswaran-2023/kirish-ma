04 · Operating rules

The same components, deliberately different order

Reversing shutdown order keeps the pump from running against a closed isolation valve.

Turn the farm flow ON

1 · Valve OPEN→ confirm →2 · Pump START→ confirm

The next command is created only when the previous component reports the expected state.

Turn the farm flow OFF

1 · Pump STOP→ confirm →2 · Valve CLOSE→ confirm

OFF walks the configured flow in reverse, using each component's matching shutdown action.

Failure behaviorA command expires after 45 seconds if feedback does not confirm the expected state. The run and step are marked timed out and a critical site alert is raised. Devices with no recent feedback are marked offline after 120 seconds.
